# Changelog

All notable changes to Dev-Ashy OS will be documented in this file.

## [0.1.0] - 2026-10-04

### Added
- Initial release of Dev-Ashy OS
- Ubuntu 24.04 LTS base
- Dev-Ashy branding and themes
- Developer tools pre-installed
- AI tooling support (Ollama, OpenCode, Gemini CLI, Hermes Agent)
- Security tools (Nmap, Metasploit, Wireshark, etc.)
- Mobile development support (React Native, Expo, Android SDK)
- Creative tools (FFmpeg, OBS Studio, GIMP, Blender)
- First-boot setup script
- Optional installer scripts for each category
- ISO build system
- QEMU testing framework
- Verification tools
- Release automation

### Known Issues
- This is an alpha release
- Some features may not work as expected
- Please report issues on GitHub
