# Dev-Ashy OS System Requirements

## Minimum Requirements

| Component | Specification |
|-----------|--------------|
| CPU | 64-bit dual-core processor |
| RAM | 4 GB |
| Disk Space | 25 GB |
| USB | 4 GB flash drive |
| Network | Internet connection recommended |

## Recommended Requirements

| Component | Specification |
|-----------|--------------|
| CPU | 64-bit quad-core processor (Intel i5/AMD Ryzen 5 or better) |
| RAM | 8 GB or more |
| Disk Space | 50 GB SSD |
| USB | 8 GB USB 3.0 flash drive |
| Network | Broadband internet connection |

## Supported Architectures

- **x86_64 (AMD64)** — Primary target
- **aarch64 (ARM64)** — Experimental support

## Graphics

- Integrated graphics: Intel HD 4000 or better
- Dedicated GPU: Optional but recommended for creative work
- Display: 1280x720 minimum, 1920x1080 recommended

## Virtualization

Dev-Ashy OS can run in virtual machines:

| Platform | Minimum RAM | Notes |
|----------|-------------|-------|
| VirtualBox | 4 GB | Enable 3D acceleration |
| VMware | 4 GB | Best performance |
| QEMU/KVM | 4 GB | Native performance |
| Parallels | 4 GB | macOS only |
| Hyper-V | 4 GB | Windows Pro/Enterprise |

## BIOS/UEFI Requirements

- UEFI boot mode recommended
- Legacy BIOS supported
- Secure Boot may need to be disabled
- USB boot must be enabled

## Network

- Ethernet: 100 Mbps or faster
- WiFi: 802.11n or faster
- Internet connection required for updates and additional packages
